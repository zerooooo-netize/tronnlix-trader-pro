# Tronnlix Trade: Your Premium Brokerage

Build a premium full-stack forex broker platform called Tronnlix Trade.

The platform must NOT look AI generated.

It should look like it was designed by senior product designers from Stripe, Revolut, Binance, Coinbase, TradingView and Linear.

Every page should feel handcrafted.

Avoid repetitive layouts.

Use premium spacing.

Use asymmetrical sections.

Use meaningful illustrations.

Use subtle premium animations.

Everything must be mobile responsive.

Use Lovable Cloud with Supabase.

Use production-ready architecture.

Enable Row Level Security everywhere.

Implement audit logs.

Implement activity logs.

Implement notifications.

Implement soft deletes.

Implement loading skeletons.

Implement beautiful empty states.

Use Framer Motion.

Use Lucide icons.

Use React + Tailwind.

Everything should be modular.

==================================================
USER ROLES
==================================================

Only create three roles.

1.
Super Admin

Has unrestricted access.

Only one account can ever become Super Admin.

The role cannot be edited, deleted or reassigned from the dashboard.

Only database changes can replace the Super Admin.

Super Admin controls everything.

2.
Admin

Can manage users.

Manage deposits.

Manage withdrawals.

Manage copy traders.

Manage support.

Manage site settings.

Manage themes.

Manage crypto wallets.

Manage CMS.

Manage emails.

View analytics.

Cannot modify Super Admin.

3.
User

Can manage only their own account.

Cannot access admin pages.
